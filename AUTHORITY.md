# Authority model

Access is not authority. Model capability is not authority. A repository write is not a public decision.

| Level | Agent may | Required human control |
|---|---|---|
| Observe | Search, classify, compare, summarize | Source and provenance checks |
| Prepare | Draft options, translations, reports, tests | Review before circulation |
| Recommend | Rank options and explain tradeoffs | Named official accepts or rejects |
| Operate | Execute reversible, delegated administrative steps | Explicit mandate, logging, rollback |
| Decide | Never autonomously | Authorized officeholder or institution |
| Coerce | Never | Statutory process, accountable humans, appeal rights |

Any matter affecting rights, benefits, taxation, healthcare, education access, employment, policing, migration, justice, or essential services requires a legal basis, fundamental-rights assessment, named human oversight, explanation, and an appeal route.
